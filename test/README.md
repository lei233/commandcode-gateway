# 后续验收范围

当前尚无测试实现。架构定案后，功能编码应包含以下验收：

- Chat JSON 与 SSE 文本输出、推理内容、用量及结束顺序。
- Authorization / x-api-key 的凭据归一、前缀兼容、冲突和缺失。
- 常用参数实际到达 adapter 发出的请求，不支持的参数明确报错。
- 工具调用 ID 保持、多个调用、乱序回填、缺失或重复回填、两轮闭环。
- 图片 data URL 和远程 URL、多图顺序、图片格式与尺寸验证、附件实际进入上游请求。
- 图片下载取消、超限、重定向及地址限制，附件在正常和异常结束后释放。
- 上游 401/403/429、Retry-After、超时、缺少终态、半段工具参数。
- 客户端断开、背压、请求体超限、服务关闭和并发请求隔离。
- 模型列表与健康检查。

日常测试使用合成凭据与模拟上游。真实上游验收单独显式执行；当前尚未执行真实调用。
